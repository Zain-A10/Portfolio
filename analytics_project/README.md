# Point-of-Sale Fraud Analytics Project

## Overview

This project simulates a fraud analytics environment similar to those used by financial institutions to monitor transaction activity, identify fraud patterns, and support risk management decisions.

## Technologies Used

- PostgreSQL
- SQL
- Python
- Pandas

## Dataset

Generated 5,000 simulated point-of-sale transactions containing:

- Customer information
- Merchant information
- Transaction amounts
- Payment methods
- Fraud indicators
- Fraud types

## Analyses Performed

### Fraud Rate Analysis

Calculated overall fraud rates across all transactions.

### Merchant Risk Analysis

Identified high-risk merchants and merchant categories.

### Fraud Loss Reporting

Measured financial losses associated with fraudulent transactions.

### Customer Risk Analysis

Detected customers with repeated fraud activity.

### Geographic Analysis

Evaluated fraud rates across different states.

### Payment Method Analysis

Compared fraud trends across payment methods.

## Advanced SQL Concepts

- GROUP BY
- HAVING
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Ranking Functions

## Business Impact

The project demonstrates how SQL can be used to transform transaction data into actionable fraud-risk insights and support business decision-making.
